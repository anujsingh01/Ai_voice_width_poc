Prestige Assistant

Demo page. Click the red chat button in the bottom-right corner, then type a question or tap the mic and talk.

Voice input works in Chrome, Edge and Safari. Firefox gets text chat only.

Add it to the store

Paste this before </body> on shop.ttkprestige.com, using your deployed server's address:

<script src="https://YOUR-SERVER/widget.js"
        data-server="https://YOUR-SERVER"
        data-title="Prestige Assistant"
        data-color="#c8102e"
        data-lang="en-IN" defer></script>
