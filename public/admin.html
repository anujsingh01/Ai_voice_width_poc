ElevenLabs voice

When a key is saved, every browser speaks with this voice instead of the browser's own. Credits come from your ElevenLabs plan. Create the key at elevenlabs.io → Developers → API keys, with "Text to Speech" and "Voices: read" allowed ("User: read" also shows the credits left).

Press Test to load your voices. Indian-accent voices are listed first. More are in the ElevenLabs voice library: add one there and press Test again.

WhatsApp number check

After the free questions, the chat asks for a WhatsApp number and sends a 6-digit code before it answers more. This stops one person from running up the bill. Meta charges about ₹0.115 + GST for each code it delivers in India. Set it up in Meta Business → WhatsApp Manager: approve an Authentication template with a "Copy code" button, then create a System User access token with the whatsapp_business_messaging permission.

Monthly budget

Sonnet gives the best answers. When its budget is used up, Haiku answers every question until the 1st of the month. At the hard limit the chat pauses and shows the customer-care number. Set the same hard limit in the Anthropic console.
